# Privacy

Unhooked is designed to remove distracting and intrusive parts of Instagram.

## Data collection

Unhooked itself does not collect analytics, credentials, personal data, or usage data.

The GitHub Pages site does not load third-party analytics scripts.

## Credentials

Unhooked does not collect, store, proxy, or transmit Instagram usernames, passwords, or session tokens.

Authentication is handled by Instagram inside the app.

## Network behavior

Unhooked may block or modify some Instagram app behavior depending on the active patches.

Where possible, patches related to ads, telemetry, or network behavior should be documented. The README documents the current blocked network paths.

## Third parties

Unhooked is not affiliated with Instagram, Meta, Facebook, or any third party.

## Recommendation

If you do not want to trust a prebuilt APK, build Unhooked yourself from source.
