# Frequently Asked Questions

## What is Unhooked?

Unhooked is an open-source Android patch for Instagram that removes distracting features such as feed, Reels, Explore, ads and telemetry while keeping useful features like DMs, stories, profiles, search and notifications.

## Is Unhooked affiliated with Instagram or Meta?

No. Unhooked is an unofficial community project and is not affiliated with Instagram or Meta.

## Does Unhooked collect my password?

No. Unhooked does not collect, store, proxy, or transmit your credentials.

Instagram login still happens through the Instagram app itself.

## Can I build it myself?

Yes. Users are encouraged to build the APK themselves using the documented patching process.

## Why does Android warn me before installing the APK?

Unhooked is distributed outside the Google Play Store, so Android may show warnings before installation. This is expected for APKs installed manually.

Only install APKs from the official Unhooked GitHub releases, or build the APK yourself.

## Classic APK or Clone APK?

The classic APK replaces the regular Instagram app because it keeps Instagram's original package ID.

The clone APK is designed to install alongside the regular Instagram app by using a different package ID.

Use the clone APK if you want to keep the official Instagram app installed at the same time.

## Can my Instagram account be banned?

Unhooked is unofficial and modifies the Instagram Android app. This may violate Instagram's terms of service. Use it at your own risk.

## Why not use a WebView wrapper?

Unhooked patches the real Android Instagram app instead of wrapping the website in a WebView. This allows it to keep the native app experience while removing specific distracting features.

## Why not use an accessibility-service blocker?

Accessibility blockers usually react to the interface after it appears. Unhooked aims to remove or block distracting parts more directly through patches.

## Does Unhooked remove all distractions?

The goal is to remove the most addictive parts while keeping useful social features. Some features may change or break when Instagram updates its app.
